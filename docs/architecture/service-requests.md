# Service requests and quotes

SRS J2, F-050..F-052. Design: [ADR-0021](../adr/0021-service-requests-and-quotes.md).

> Quotes are informational. Every quote and agreement carries: **"Payment is arranged directly with the provider. FleetTrust doesn't process or verify payments."** and the scam warning **"Never pay a deposit to an account you can't verify. …"**

## Flow

1. **Upload photos (optional):** `POST /v1/service-request-attachments` returns `{ attachmentId, upload }`. `PUT` the bytes to `upload.url`, then `POST …/:attachmentId/complete`.
2. **Create the request:** `POST /v1/me/service-requests` (personal) or `POST /v1/orgs/:orgId/service-requests` (fleet). This uses one `service_requests.daily` unit.
3. **Providers respond:** they see it in `GET /v1/orgs/:orgId/inquiries`, open it (marked `viewed`), then quote, revise, withdraw or decline.
4. **The requester accepts a quote:** `POST …/:requestId/quotes/:quoteId/accept`. This records an informational agreement.
5. **Either side finishes:** marks it completed, or adds evidence. The requester can cancel; the accepted provider can cancel, which reopens the request.

## Creating a request

```json
{
  "clientRequestId": "0196f2a8-6b7c-7d00-9e00-1a2b3c4d5e6f",
  "category": "towing",
  "vehicle": {
    "vehicleType": "heavy_truck",
    "make": "Volvo",
    "model": "FH16",
    "year": 2021,
    "registration": "CA 123-456"
  },
  "location": { "lng": 18.4241, "lat": -33.9249 },
  "locationNote": "Truck stop bay 4",
  "description": "Air brake warning light on, losing pressure slowly.",
  "urgency": "urgent",
  "neededBy": null,
  "photoIds": ["…"],
  "target": { "mode": "match", "radiusKm": 25 },
  "fleetBranchId": null
}
```

| Field             | Notes                                                                                                                                                 |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `clientRequestId` | A UUID generated by the client. **Reuse it on retry:** the same request comes back and no quota is used twice                                         |
| `target`          | `{ mode: "direct", providerIds: [1–5] }` or `{ mode: "match", radiusKm: 1–100 }` (up to 10 providers by relevance)                                    |
| `urgency`         | `routine`, `soon` or `urgent`. Emergencies are a separate flow (Prompt 18)                                                                            |
| `photoIds`        | Up to 6 finished uploads by the caller, not yet used on a request                                                                                     |
| `fleetBranchId`   | Fleet requests only. Branch-scoped members always file under their own branch                                                                         |
| `vehicleId`       | Optional: a vehicle you can access ([vehicles.md](vehicles.md)). Its details replace the snapshot, and the accepted provider can add a service record |

**Errors:**

- **403 `quota_exceeded`:** the daily limit is reached.
- **422 `no_matching_providers`:** nothing matched; no quota is used.
- **400:**
  - `provider_not_matching`: a chosen provider doesn't offer the category or vehicle type.
  - `attachment_not_ready`: a photo isn't finished, isn't the caller's, or is already used.
  - `not_a_fleet`: the fleet route was called for a provider organization.

## Routes

**Requester, personal:** `/v1/me/service-requests` (signed in).
**Requester, fleet:** `/v1/orgs/:orgId/service-requests` (`requests.create`; `requests.manage` sees the whole fleet).

| Method & path                             | Notes                                              |
| ----------------------------------------- | -------------------------------------------------- |
| `POST /`                                  | Create (30 per hour per user)                      |
| `GET /`                                   | Latest 50                                          |
| `GET /:requestId`                         | Recipients, quotes, agreement, attachments, events |
| `POST /:requestId/quotes/:quoteId/accept` | Open request and active, unexpired quote only      |
| `POST /:requestId/cancel`                 | `{ reason }`. From `open` or `accepted`            |
| `POST /:requestId/complete`               | From `accepted`                                    |
| `POST /:requestId/evidence`               | `{ note?, photoIds? }` (at least one)              |

**Provider inbox:** `/v1/orgs/:orgId/inquiries` (`requests.respond`: owner, admin, manager, staff; branch-scoped members see their branch's inquiries).

| Method & path                                 | Notes                                                                                          |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `GET /`                                       | Latest 50                                                                                      |
| `GET /:recipientId`                           | Marks it `viewed`                                                                              |
| `POST /:recipientId/quotes`                   | `{ price, message?, availableFrom?, validDays 1–30 }`. A new quote supersedes the previous one |
| `POST /:recipientId/quotes/:quoteId/withdraw` | While the request is open                                                                      |
| `POST /:recipientId/decline`                  | `{ reason? }`                                                                                  |
| `POST /:recipientId/cancel`                   | Accepted provider only, `{ reason }`. The request reopens                                      |
| `POST /:recipientId/complete`                 | Accepted provider only                                                                         |
| `POST /:recipientId/evidence`                 | `{ note?, photoIds? }`                                                                         |

**Attachments:**

| Method & path                                                   | Notes                                                              |
| --------------------------------------------------------------- | ------------------------------------------------------------------ |
| `POST /v1/service-request-attachments`                          | `{ contentType: image/jpeg\|png\|webp, size ≤ 8 MB }`              |
| `POST /v1/service-request-attachments/:attachmentId/complete`   | Scan, strip metadata, store privately                              |
| `GET /v1/service-requests/:requestId/attachments/:attachmentId` | Requester side or a recipient's members; `Cache-Control: no-store` |

## What each side sees

| Field                      | Requester | Recipient before acceptance |  Accepted provider   |   Other providers    |
| -------------------------- | :-------: | :-------------------------: | :------------------: | :------------------: |
| Location                   |   exact   |       rounded (~1 km)       |        exact         |       rounded        |
| Address note, registration |     ✓     |              —              |          ✓           |          —           |
| Quotes                     |    all    |             own             |         own          |         own          |
| Events                     |    all    |    request-wide and own     | request-wide and own | request-wide and own |
| Requester's photos         |     ✓     |              ✓              |          ✓           |          ✓           |
| A provider's evidence      |     ✓     |          own only           |       own only       |          —           |

## Statuses

- **Request:** `open`, `accepted`, `completed`, `cancelled`, `expired` (open past 14 days).
- **Recipient:** `pending`, `viewed`, `quoted`, `declined`, `accepted`, `not_selected`, `cancelled`.
- **Quote:** `active`, `superseded`, `withdrawn`, `accepted`, `not_selected`, `expired` (past `validUntil`).

## Events

The history is append-only (a database trigger refuses updates and deletes). Event types: `created`, `sent`, `viewed`, `quote_submitted`, `quote_revised`, `quote_withdrawn`, `declined`, `quote_accepted`, `not_selected`, `cancelled`, `provider_cancelled`, `reopened`, `completed`, `evidence_added`. Each one is also enqueued in the outbox as `ServiceRequest<Type>`, ready for notifications (Prompt 17).

## Data

| Table                         | Notes                                                                                                                                                                                                     |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `service_requests`            | Personal (`requester_user_id`) or fleet (`requester_organization_id`, kind `fleet` by composite FK). Unique `clientRequestId` per requester. Vehicle snapshot, location (geography), status, `expires_at` |
| `service_request_recipients`  | One per provider. Routed branch, distance, status. **The ID anchors the request's conversation (Prompt 17)**                                                                                              |
| `service_quotes`              | Indicative price columns with a shape check; at most one active or accepted quote per recipient                                                                                                           |
| `service_request_attachments` | Private photos: quarantine key, then storage key in the sensitive bucket                                                                                                                                  |
| `service_request_events`      | Append-only history                                                                                                                                                                                       |
