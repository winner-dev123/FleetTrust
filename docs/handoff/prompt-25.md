## Assumptions

- **Stack:**
  - Expo SDK 58 **dev builds**, not Expo Go, with React Native Firebase 27 (the OQ-20 default);
  - Expo Router for screens and deep links;
  - native projects generated by `expo prebuild` and not committed.
- **The app uses the existing API only.** No API, database or migration changes. Everything goes through `@fleettrust/sdk`.
- **Sign-in is email link only for now.** Google and Apple must ship together on iOS (KC-01), and both need native SDK setup and the owner's accounts.
- **People first.** Business, fleet, plan and appeal tools stay on the web, and the Account screen links there.
- **Real devices:** the device-level checks are a written plan. Running them needs the owner's Firebase project files, a dev build, and Apple and Google developer accounts (OQ-19). The same behaviour is simulated in Jest on a fake device.

## Evidence (actual results)

- **`pnpm check`:** passes (prettier, module guard: 804 files, 39/39 turbo tasks).
- **Tests:**
  - mobile **81** (was 5): 7 logic suites, 4 screen suites and a guard suite;
  - web 54 (10 tests moved to the shared packages with their code);
  - ui 43, types 84, sdk 32, api 326, db 96 + 6 skipped, local-infra 44, repo-guards 25, env 5.
- **Mobile production bundle:** `expo export` builds the iOS and Android bundles (3.9 MB each).
- **Web browser tests:** 18 of 18 pass locally (re-run because the web now imports the moved helpers).
- **Drift check:** no schema changes.
- **Checked that the tests catch regressions** (each broke the tests, then was restored):
  - a new alert ID on retry;
  - skipping the alert confirmation;
  - trusting links from any host;
  - turning on background location;
  - asking for notifications at launch;
  - keeping drafts after sign-out;
  - removing the message `seq` dedupe;
  - allowing a request to be sent offline.
- **Bugs found while testing (fixed):**
  - Expo Router passes the app's own `/auth/finish?link=…` path back through the deep-link filter, which dropped it. The filter now accepts that path only with a trusted sign-in link.
  - The chat screen re-subscribed on every new message (reconnecting each time). It now subscribes once per conversation.
  - Two Account buttons had the same name ("Open Settings"). The location one is now "Location settings".

## CI findings (fixed)

- **Dependency audit (high):** `@react-native-firebase/app` pulls the Firebase JS SDK (its web fallback), whose Firestore pinned `@grpc/grpc-js` 1.9.16 (GHSA-m9gg-hp2v-232j, fixed in 1.13.6). The phone app runs the native SDKs and never loads that code. A pnpm override in `pnpm-workspace.yaml` lifts old versions to 1.14.7 (already used elsewhere in the repo); `pnpm audit --prod --audit-level high` passes.
- **Test timeout:** one screen test (typing a sentence and rendering the app twice) took longer than Jest's 5-second default on the CI runner. Screen tests render the whole app, so the mobile Jest timeout is now 30 seconds.
