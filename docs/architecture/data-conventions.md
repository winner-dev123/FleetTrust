# Data conventions

Rules every table follows. Where a rule can be checked automatically, `packages/db/test/conventions.test.ts` checks it against the migrated catalog, so a new table that breaks a rule fails CI.

| Area             | Convention                                                                                                                                                                                                                                                                                                                                                                                      | Enforced by                                                                                                                        |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Primary keys     | `id uuid`. The app generates **UUIDv7** (time-ordered, better index locality); `gen_random_uuid()` is a fallback default for raw-SQL inserts. Natural keys only for reference data (`currencies.code`)                                                                                                                                                                                          | conventions test (`id` is uuid, every table has a PK)                                                                              |
| Timestamps       | `timestamptz` only. `created_at` and `updated_at` default `now()`; `updated_at` is maintained by the `set_updated_at()` trigger, never by application code alone                                                                                                                                                                                                                                | conventions test (no `timestamp without time zone`; every `updated_at` table has the trigger)                                      |
| Naming           | `snake_case` tables (plural) and columns; indexes `<table>_<cols>_idx`; checks `<table>_<rule>`                                                                                                                                                                                                                                                                                                 | review                                                                                                                             |
| Tenant scoping   | Org-scoped tables have `organization_id uuid NOT NULL`, leading at least one index. Queries go through repositories that take a `TenantContext` and apply `tenantFilter()`                                                                                                                                                                                                                      | conventions test (uuid + leading index); `expectTenantIsolation()` per resource ([test plan](../qa/tenant-isolation-test-plan.md)) |
| Enumerations     | `text` + `CHECK (col IN (...))` rather than Postgres `ENUM` types (cheaper to evolve). Drizzle's `text({ enum })` is TypeScript-only, so always add the CHECK                                                                                                                                                                                                                                   | review; tests per table                                                                                                            |
| Soft delete      | **Hard delete by default.** `deleted_at timestamptz` only where a documented reason exists: legal retention, a user-facing undo or grace period, or audit references that must stay resolvable. Soft-deleted tables need partial unique indexes (`WHERE deleted_at IS NULL`) and repository queries that exclude deleted rows. Personal data is purged after the grace period, not kept forever | review                                                                                                                             |
| Audit            | State changes that affect trust, money-like data, safety, permissions or plans write an `audit_events` row **in the same transaction** via `recordAuditEvent()`. `audit_events` is append-only (database triggers reject UPDATE/DELETE/TRUNCATE). Never put secrets, tokens, document contents or message bodies in `metadata`                                                                  | DB triggers + tests                                                                                                                |
| Domain events    | Written to `outbox_events` in the same transaction as the change (`enqueueOutboxEvent()`), published by a relay (ADR-0007). Event types are PascalCase; consumers are idempotent                                                                                                                                                                                                                | CHECK constraint + tests                                                                                                           |
| Spatial          | Points are `geography(Point, 4326)` (metres on the WGS 84 spheroid) via the `geographyPoint` column type, with a **GiST index**. Use `withinMeters()` / `distanceMeters()` / `withinBoundingBox()`. Coordinates are validated before reaching SQL                                                                                                                                               | helpers + spatial tests                                                                                                            |
| Money            | No money moves through the platform. Prices are indicative: `numeric(12,2)`-style amount + `currency` (FK to `currencies.code`). `currencies.display_decimals` is display precision only, never storage precision                                                                                                                                                                               | review (Prompts 08, 11)                                                                                                            |
| Foreign keys     | Always declared, with an index on the referencing column. `ON DELETE` chosen deliberately per relation (default `RESTRICT`)                                                                                                                                                                                                                                                                     | review                                                                                                                             |
| Secrets & PII    | No secrets in the database. Identity-document contents live in Cloud Storage (ADR-0006), not in rows. Columns holding sensitive PII get application-level encryption (Prompt 27)                                                                                                                                                                                                                | review                                                                                                                             |
| Postgres version | Target **Postgres 17** (Cloud SQL). PGlite tests run 18; don't use 18-only features                                                                                                                                                                                                                                                                                                             | `pnpm test:db` on 17                                                                                                               |
