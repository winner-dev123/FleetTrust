# Threat model and risk register

- **Scope:** FleetTrust API (Cloud Run), web (Firebase App Hosting), mobile app, PostgreSQL/PostGIS (Cloud SQL), Cloud Storage, Firebase Auth / Identity Platform, FCM, Redis.
- **Method:** STRIDE per component, then a risk register.
- **Review:** every critical or high risk must be **mitigated** (with the evidence named) or **risk-accepted** (with an owner and a reason). Review this document before launch (Prompt 29) and whenever a new module adds data or a trust boundary.

## Assets

| Asset                                                   | Why it matters                                               |
| ------------------------------------------------------- | ------------------------------------------------------------ |
| Identity and business documents                         | Most sensitive data held; theft enables identity fraud       |
| Locations (searches, requests, emergency alerts)        | Physical safety: stalking, theft from parked vehicles        |
| Private messages and request photos                     | Personal and commercial confidentiality                      |
| Accounts and sessions                                   | Takeover gives access to everything above                    |
| Staff powers (verification, plans, moderation, support) | Abuse affects every user; trust labels must stay honest      |
| Trust labels and Power User status                      | The product's credibility; can't be bought or faked          |
| Emergency alerts                                        | Safety-critical: must not be blocked, faked or over-promised |

## Trust boundaries

1. Browser or phone → API (internet; bearer token plus App Check).
2. API → database, storage and Redis (private network, service accounts).
3. API → Firebase Admin, KMS, FCM, ClamAV (Google APIs, workload identity).
4. Staff console → staff API (MFA, roles, confirmations).
5. Upload URL → quarantine bucket (signed, size- and type-bound).

## STRIDE summary

| Threat                     | Main controls                                                                                                                                                                                |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Spoofing**               | Firebase ID tokens verified on every request; revocation checks on sensitive routes; App Check (enforced in production); staff MFA; email-link sign-in (no passwords)                        |
| **Tampering**              | Server-side validation (zod) of every input; database constraints; idempotency keys; audit log; signed upload URLs; AES-GCM authentication on encrypted files                                |
| **Repudiation**            | `audit_events` for every staff action and sensitive user action (exports, deletions, consents); request IDs correlate logs; audit search is itself audited                                   |
| **Information disclosure** | Derived access checks (404 for no access); approximate locations for visitors; envelope encryption for documents and private photos; private buckets; strict security headers; redacted logs |
| **Denial of service**      | Rate limits per user and IP (Redis when deployed); quotas; pagination limits; Cloud Run autoscaling; emergency routes exempt from quotas but soft-flagged                                    |
| **Elevation of privilege** | Role checks per organization (RBAC) and per staff role; nobody changes their own staff roles; module boundary lint (for example emergency can't depend on entitlements)                      |

## Risk register

Severity: **C**ritical, **H**igh, **M**edium, **L**ow.

| ID   | Threat                                         | Sev | Status            | Evidence / reason                                                                                                                                                                                                                                                                                                |
| ---- | ---------------------------------------------- | --- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-01 | Cross-tenant data access (IDOR)                | H   | Mitigated         | Access derived per request; **automated tenant penetration test** over every private route with an ID (over 270 routes, real victim IDs, two attacker types; `test/security/tenant-pentest.e2e-spec.ts`); anonymous sweep (401 everywhere private); [tenant isolation plan](../qa/tenant-isolation-test-plan.md) |
| T-02 | Account takeover through a stolen session      | H   | Mitigated         | Short-lived ID tokens; revocation on sensitive routes; "sign out everywhere"; recent sign-in for irreversible actions (account deletion, staff actions); App Check                                                                                                                                               |
| T-03 | Compromised or abusive staff account           | C   | Mitigated         | Staff MFA enforced by the API; least-privilege roles; no self-grant; typed confirmations; audit search (ADR-0033)                                                                                                                                                                                                |
| T-04 | Malicious uploads (malware, polyglots, script) | H   | Mitigated         | Signed, size-bound upload URLs to a quarantine bucket; magic-byte check; ClamAV (required when deployed); image metadata stripping; downloads with `nosniff` and a sandbox CSP (ADR-0006)                                                                                                                        |
| T-05 | Leak of identity documents                     | C   | Mitigated         | KMS envelope encryption per file; five-minute, single-use, audited viewing links; deleted 90 days after a decision; erased on account deletion                                                                                                                                                                   |
| T-06 | Location tracking or stalking                  | H   | Mitigated         | Visitors see approximate locations; alert location erased when the alert closes; providers see an approximate area; mobile asks for foreground location only, never background                                                                                                                                   |
| T-07 | Stored XSS through community content           | H   | Mitigated         | Strict document schema (no HTML), `safeHref`, React escaping; native rendering on mobile; CSP on the web (see R-02)                                                                                                                                                                                              |
| T-08 | SQL injection                                  | H   | Mitigated         | Drizzle queries and `sql` tagged templates are parameterized; `LIKE` input escaped (audit search)                                                                                                                                                                                                                |
| T-09 | Brute force and credential stuffing            | M   | Mitigated         | Passwordless sign-in; failed-auth limit per IP (20 per 10 minutes); App Check                                                                                                                                                                                                                                    |
| T-10 | Spam, scams and report brigading               | M   | Mitigated         | Quotas and rate limits; scam warnings; auto-hide threshold (setting); `signups.paused`; sanctions and appeals                                                                                                                                                                                                    |
| T-11 | Emergency misuse, or over-reliance on alerts   | H   | Mitigated / owner | Never quota-limited, soft-limit flagging, guidance first, wording guard tests; **legal review OQ-04 pending (owner)**                                                                                                                                                                                            |
| T-12 | Payment fraud                                  | M   | Mitigated         | No payments in the product (ADR-0008); scam warnings on quotes and chats                                                                                                                                                                                                                                         |
| T-13 | Clickjacking                                   | M   | Mitigated         | `X-Frame-Options: DENY` and `frame-ancestors 'none'` on web and API (tests)                                                                                                                                                                                                                                      |
| T-14 | Secrets leaked                                 | H   | Mitigated         | Secret Manager; gitleaks over full history in CI; config validation refuses development settings when deployed; no secrets in `NEXT_PUBLIC_*` / `EXPO_PUBLIC_*` ([secrets](secrets-management.md))                                                                                                               |
| T-15 | Vulnerable dependencies                        | M   | Mitigated         | `pnpm audit --prod --audit-level high` gates CI; minimum release age; install scripts blocked by default; Dependabot (see R-03)                                                                                                                                                                                  |
| T-16 | Denial of service at the edge                  | M   | Accepted (R-05)   | App-level limits exist; edge protection comes with deployment (Prompt 29)                                                                                                                                                                                                                                        |
| T-17 | Keeping data too long                          | M   | Mitigated         | Daily retention job and [policy](data-retention.md)                                                                                                                                                                                                                                                              |
| T-18 | Not noticing an attack                         | M   | Partly            | Audit log, structured redacted logs, traces; alerting and on-call are Prompt 29                                                                                                                                                                                                                                  |
| T-19 | SSRF                                           | L   | Mitigated         | The API never fetches user-supplied URLs; vendor endpoints are fixed by configuration; tile URLs are rendered by clients only (https checked)                                                                                                                                                                    |
| T-20 | CSRF                                           | L   | Mitigated         | Bearer tokens in a header, no auth cookies; CORS allowlist                                                                                                                                                                                                                                                       |
| T-21 | Lock-screen message previews                   | L   | Mitigated         | Push previews off by default                                                                                                                                                                                                                                                                                     |
| T-22 | Data left on a shared phone                    | M   | Mitigated         | The app stores no tokens itself; drafts and queued messages are per user and erased at sign-out; push unregistered at sign-out                                                                                                                                                                                   |
| T-23 | Database checks that let NULL through          | L   | Fixed             | Migration 0041 (`COALESCE` in the two Prompt 09 checks); database test                                                                                                                                                                                                                                           |
| T-24 | Private photos readable in storage             | M   | Fixed             | Chat and request photos envelope-encrypted (Prompt 27); test reads the raw object                                                                                                                                                                                                                                |
| T-25 | Privacy rights not honoured                    | H   | Fixed             | Export, deletion and consent records ([privacy](privacy.md)); API, web and mobile tests                                                                                                                                                                                                                          |
