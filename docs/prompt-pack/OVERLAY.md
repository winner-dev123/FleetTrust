# FleetTrust overlay for the prompt pack

The files in this folder are the original prompt pack, copied unchanged. This overlay records **decisions made after the pack was written**. When running any numbered prompt, apply its global instructions (`README.md` in this folder) **plus this overlay**. Where they conflict, the overlay wins, because it reflects owner decisions.

## Platform decision (2026-11-19)

The owner chose a **Firebase hybrid on Google Cloud** ([ADR-0004](../adr/0004-firebase-hybrid-platform.md)). The deployment provider is no longer "unknown"; it is Google Cloud. PostgreSQL/PostGIS, NestJS, Next.js and React Native remain as the pack specifies.
